# 🎉 Aplicación Web - Semana de Aniversario Uniremington

Página web interactiva y moderna para la agenda oficial de eventos de la Semana de Aniversario de la Corporación Universitaria Remington (**Uniremington**).

---

## 🌟 Características Principales

- **Diseño Moderno e Institucional:** Estilos visuales acordes a la identidad institucional de Uniremington con efectos visuales dinámicos.
- **Fondo Interactivo:** Animación de aurora boreal mediante CSS y lienzo (`<canvas>`) con constelación de partículas interactivas en JavaScript puro.
- **Tarjetas de Eventos:** Cuadrícula responsiva que presenta cada una de las actividades programadas durante la semana con sus respectivas fechas y tipo de participación (Obligatoria / Opcional).
- **Integración con Excel:** Acceso directo para consultar y descargar la programación detallada en el archivo `Eventos_Uniremington_Fest.xlsx`.
- **Diseño Totalmente Responsivo:** Adaptado para una visualización óptima tanto en dispositivos móviles como en pantallas de escritorio.

## 📅 Agenda de Eventos

| **24 de septiembre** | Declamadores Invitados | Opcional |
| **25 de septiembre** | Entrega de Distinciones | Obligatoria |
| **26 de septiembre** | Día de la Familia y Feria Empresarial | Opcional |

---

## 🛠️ Tecnologías Utilizadas

- **HTML5:** Marcado semántico y accesible.
- **CSS3:** Variables CSS, animaciones fluidas, efecto Glassmorphism y diseño responsivo con CSS Grid y Flexbox.
- **JavaScript (Vanilla):** Sistema de partículas y efectos interactivos sobre el fondo canvas.
- **Microsoft Excel:** Hoja de cálculo integrada con la información completa de la agenda.
